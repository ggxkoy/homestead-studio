# 庭院 · 空间规划

基于手绘宅基地平面图的三维家具布置网站，部署在 GitHub Pages。

## 功能

- 三维剖视、俯视摆放、完整外观、房间聚焦。
- 国风剖面效果图，可查看大图和下载；仅作静态风格参考，不随家具摆放更新。
- 每个房间独立添加家具；鼠标或触控拖动、旋转、调整长宽高和位置。
- 实木家具库、家具复制和删除、15 步撤销重做。
- 房间参考照片与每件家具参考照片分别存储，支持预览和删除。
- IndexedDB 本机自动保存；JSON 导出/导入包含全部照片、尺寸和家具位置。
- 家具限制在所属房间内，重叠时显示提示。

选择左侧房间 → 点击下方家具 → 拖动摆放。选中家具后，画布上方显示旋转工具，可左转 / 右转 90°，或输入精确角度（逆时针计量，自动归一至 0–359°）。右侧详情也可调整角度、尺寸或上传照片。`R` 左转，`Shift+R` 右转，方向键移动 5 cm（Shift 为 25 cm），Delete 删除，Ctrl/Cmd+Z 撤销。角度随方案自动保存，并包含在导出备份中。

## 数据与图纸假设

照片和方案仅保存在当前浏览器，不上传至 GitHub 或服务器，也不会自动同步到其他设备。使用“导出方案”备份；换设备后导入同一文件即可。清除网站存储会删除本机方案。

尺寸按第二张图纸 12.96 × 18.30 m，层高 3.30 m 暂定；客厅净宽、局部分隔和南北尺寸闭合仍需实测复核。东侧空间为平地过道，没有楼梯，也没有楼梯围隔。完整外观沿用暂定的平屋顶，仅作空间预览。原始图纸、个人照片和本机方案不包含在仓库内。

## 本地开发

Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build
```

生产构建在 `dist/`，相对资源路径可在 GitHub Pages 项目子目录运行。推送 `codex/homestead-studio` 分支自动测试、构建并部署。
